# Метод конечных элементов для нестационарного уравнения теплопроводности

Курсовая работа (МГТУ им. Н. Э. Баумана, факультет фундаментальных наук, кафедра прикладной математики, 2025 г.). Программа на C++ решает двумерное нестационарное уравнение теплопроводности методом конечных элементов на треугольных сетках: линейные треугольные элементы, метод Бубнова–Галёркина, неявная схема Эйлера с диагонализированной матрицей теплоёмкости. Корректность проверена по точному решению на последовательности сеток.

**Коротко:**

- линейный треугольный конечный элемент, слабая постановка, сборка глобальных матриц из локальных;
- неявная схема Эйлера (безусловно устойчивая, первый порядок по времени) с «сосредоточенной» (диагональной) матрицей теплоёмкости;
- проверка на задаче с точным решением: при уменьшении шага сетки вдвое и шага по времени вчетверо ошибка в норме L₂ падает примерно в 4 раза (наблюдаемый порядок около 2);
- одна внешняя зависимость: библиотека Eigen; сборка через CMake или Visual Studio;
- в репозитории: исходный код, генератор сеток, отчёт и презентация: [`docs/report.pdf`](docs/report.pdf), [`docs/presentation.pdf`](docs/presentation.pdf).

## Постановка задачи

В области Ω ⊂ ℝ² решается уравнение

$$c_V \frac{\partial T}{\partial t} = \nabla\cdot(\kappa \nabla T) + q_V, \qquad \mathbf{x}=(x,y)\in\Omega,\; t>0,$$

где T — температура, c_V = c·ρ — объёмная теплоёмкость, κ — коэффициент теплопроводности, q_V — плотность внутренних источников. Задаются начальное условие T(x, 0) = T₀(x) и условия на границе: первого рода (заданная температура), второго рода (заданный поток) или третьего рода (конвективный теплообмен).

## Метод

1. **Слабая постановка.** Умножение на пробную функцию, интегрирование по области, учёт граничных условий.
2. **Аппроксимация.** На каждом треугольнике температура линейна: T ≈ Σ Nᵢ Tᵢ(t), где Nᵢ — функции формы. Базисные функции в методе Бубнова–Галёркина совпадают с пробными.
3. **Система ОДУ.** Получается система вида

   $$[C]\,\frac{d\{T\}}{dt} + [K]\{T\} = \{F\},$$

   где [K] — матрица жёсткости, [C] — матрица теплоёмкости, {F} — вектор правой части. Локальные матрицы вычисляются на каждом элементе и добавляются в глобальные по соответствию локальной и глобальной нумерации узлов.
4. **Дискретизация по времени.** Неявная схема Эйлера, матрица [C] заменяется диагональной ([C]_diag: к каждому узлу относится треть площади каждого смежного элемента). Диагональная матрица нужна для безусловной монотонности схемы. На каждом шаге решается система

   $$\left(\frac{[C]_{diag}}{\tau} + [K]\right)\{\hat T\} = \frac{[C]_{diag}}{\tau}\{T\} + \{F\}.$$

5. **Граничные условия.** Условие второго рода входит в правую часть, третьего рода — в матрицу и правую часть. Условие первого рода учитывается методом штрафа. В тестовой задаче на всей границе нулевой поток (теплоизоляция), это условие в методе конечных элементов выполняется естественным образом.

## Тестовая задача

В прямоугольнике 0 < x < 2, 0 < y < 1:

$$T_t = \Delta T,\qquad T\big|_{t=0}=\cos(\pi x)\cos(\pi y),\qquad \frac{\partial T}{\partial n}\Big|_{\partial\Omega}=0,$$

точное решение: T(x, y, t) = exp(−2π²t) · cos(πx) · cos(πy). Параметры κ = c = ρ = 1 (файл `src/input.txt`), источников тепла нет.

## Результаты

Ошибки на момент t = 0,0025. Норма L₂ считается по элементам (значение в центре тяжести, среднее по узлам элемента против точного решения в центре тяжести), норма C — максимум модуля ошибки по узлам. Шаг по времени уменьшается в 4 раза при уменьшении h в 2 раза.

| Сетка | h        | τ            | Элементов | Узлов | Ошибка L₂        | Отношение | Ошибка C         | Отношение |
| ----- | -------- | ------------ | --------- | ----- | ---------------- | --------- | ---------------- | --------- |
| mesh16 | 0,125    | 1,0·10⁻⁴     | 256       | 153   | 2,512·10⁻²       |           | 1,475·10⁻²       |           |
| mesh32 | 0,0625   | 2,5·10⁻⁵     | 1024      | 561   | 6,336·10⁻³       | 3,96      | 7,068·10⁻³       | 2,09      |
| mesh64 | 0,03125  | 6,25·10⁻⁶    | 4096      | 2145  | 1,588·10⁻³       | 3,99      | 2,433·10⁻³       | 2,91      |

- В норме L₂ отношение ошибок на соседних сетках близко к 4, то есть наблюдаемый порядок около 2, что согласуется с оценкой O(τ + h²) при τ ∼ h².
- В норме C отношения 2,09 и 2,91 растут, но по трём сеткам нельзя сделать вывод о порядке сходимости в этой норме.
- Значения получены повторным запуском программы из этого репозитория (воспроизведение: раздел «Как воспроизвести таблицу») и могут слегка отличаться от таблицы в отчёте.

## Устройство программы

Программа находится в одном файле `src/Kyrsovaya_6sem.cpp`:

| Блок                                  | Назначение                                                                                   |
| ------------------------------------- | -------------------------------------------------------------------------------------------- |
| `read_input`, `VAR`, `read_vars`      | чтение параметров `K`, `C`, `rho` из `input.txt` (строки вида `имя = значение`)              |
| `read_mesh`                           | чтение сетки: узлы, треугольники, границы; проверка знака и малости якобиана                |
| `thermal2dfullmatrix::assemble`       | локальные и глобальная матрицы жёсткости, вектор правой части для линейного треугольника     |
| `thermal2dfullmatrix::postprocess`    | градиенты температуры и тепловые потоки по элементам; осреднение на узлы (`to_nodes`)        |
| `apply_flow`, `apply_conv`, `fix_T`   | граничные условия второго, третьего и первого рода (штраф 10²⁰)                              |
| `unsteady_solver_t`                   | диагональная матрица теплоёмкости (`assemble_mass`), шаг неявной схемы Эйлера (`time_step`)  |
| `error_analysis`                      | точное решение, ошибки в нормах L₂ и C                                                       |
| `thermal_solver::run_unsteady`        | временной цикл, печать контрольных величин, запись результатов в формате Tecplot             |

**Входные данные.** `input.txt` (κ, c, ρ) и сетка в текстовом формате: число узлов; строки `номер x y`; число элементов; строки с тремя номерами узлов (нумерация с 1); число границ; для каждой границы число узлов и их номера. Генератор сеток для прямоугольника 2×1 лежит в `tools/gen_mesh.py`.

**Выходные данные.** В консоль печатаются шаги (`step n, T_max, time`) и, в момент t = 0,0025, ошибки (`Errors at t=0.0025: L2_abs=..., C_abs=...`). Файл `results_unsteady.dat` в формате Tecplot содержит по одной зоне на шаг: X, Y, T, градиенты (Gx, Gy) и потоки (Qx, Qy).

## Происхождение кода

Программа построена на основе учебного каркаса (в выводе программы он называется `stud_fem`): чтение параметров из `input.txt`, чтение сетки, сборка матрицы жёсткости и вектора правой части для линейного треугольника, постобработка потоков, процедуры граничных условий. В рамках курсовой работы добавлены нестационарный решатель (`unsteady_solver_t`: диагональная матрица теплоёмкости и неявный шаг по времени), оценка ошибок по точному решению (`error_analysis`), вывод в формате Tecplot и исследование сходимости на последовательности сеток.

## Как собрать и запустить

Нужен компилятор с поддержкой C++17 и библиотека [Eigen](https://eigen.tuxfamily.org) 3.4 или новее (для 3.3 раскомментируйте функции `begin` и `end` в начале файла, как указано в комментарии). Eigen состоит только из заголовочных файлов: `sudo apt install libeigen3-dev` (Linux), `brew install eigen` (macOS), `vcpkg install eigen3` (Windows).

**CMake (Linux, macOS, Windows):**

```bash
cd src
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

**Visual Studio:** откройте проект `src/Kyrsovaya_6sem.vcxproj` и добавьте путь к Eigen в свойствах проекта (C/C++ → Общие → Дополнительные каталоги включаемых файлов). Собирайте в конфигурации Release.

Программа читает `input.txt` и `mesh1.txt` из **рабочей папки**, поэтому запускайте её из `src/`:

```bash
cd src
./build/heat_fem          # Windows (CMake): build\Release\heat_fem.exe
```

Имя файла сетки (`mesh1.txt`), шаг по времени `dt` и число шагов `Nt` заданы в коде (функция `run_unsteady`). Значения по умолчанию (`dt = 0,01`, `Nt = 24`, то есть t от 0,01 до 0,24) подходят для получения графика эволюции решения, но ошибки при них не печатаются: они выводятся только в момент t = 0,0025.

### Как воспроизвести таблицу ошибок

1. Создайте сетки: `python ../tools/gen_mesh.py 16 32 64 --out meshes` (из папки `src/`).
2. Для каждой строки таблицы скопируйте нужную сетку под именем `mesh1.txt` и измените в `run_unsteady` значения `dt` и `Nt`:

| Сетка  | Файл сетки        | `dt`      | `Nt` |
| ------ | ----------------- | --------- | ---- |
| mesh16 | `meshes/mesh16.txt` | `1e-4`    | 25   |
| mesh32 | `meshes/mesh32.txt` | `2.5e-5`  | 100  |
| mesh64 | `meshes/mesh64.txt` | `6.25e-6` | 400  |

3. Пересоберите и запустите программу. В конце расчёта будет строка `Errors at t=0.0025: ...`: `L2_abs` и `C_abs` — абсолютные ошибки из таблицы.

Расчёт на mesh64 занимает порядка нескольких минут (400 шагов с решением плотной системы на каждом).

### Как построить график решения

```bash
cd src
python ../tools/plot_solution.py results_unsteady.dat ../reports/figures/solution_evolution.png
```

Скрипту нужны `numpy` и `matplotlib`. Файл `results_unsteady.dat` можно также открыть в Tecplot.

## Известные ограничения

- **Плотные матрицы.** Глобальные матрицы хранятся как полные матрицы `Eigen::MatrixXd`, а система решается LU-разложением на каждом шаге. Память растёт как N², время шага как N³ (N — число узлов), поэтому сетки mesh128 и mesh256 в отчёте не использовались: для них требуются гигабайты памяти и очень много времени. Для таких сеток нужны разреженные матрицы (`Eigen::SparseMatrix`) и итерационный или разреженный прямой решатель.
- **Параметры расчёта заданы в коде.** Имя файла сетки, `dt`, `Nt` и функция источника тепла `heatGen` (в тестовой задаче 0) меняются правкой исходника и пересборкой.
- **Граничные условия в нестационарном расчёте.** Функции для условий первого, второго и третьего рода есть в коде, но в расчётах отчёта они не использовались (процедура `apply_bc` пуста): на всей границе задан нулевой поток. Условия первого и третьего рода не тестировались.
- **Проверка только на одной задаче** и только на структурированных сетках из прямоугольных треугольников. Коэффициенты κ, c, ρ постоянны.
- **Порядок сходимости в норме C не установлен** (см. таблицу результатов).
- **Контрольный вывод ошибок.** Ошибки печатаются по условию `current_time == 0.0025` (сравнение чисел с плавающей точкой на равенство). Для трёх конфигураций из таблицы оно выполняется, для других значений `dt` может не сработать.
- **Стационарный решатель** (`thermal_solver::run`) оставлен от каркаса и в расчётах не используется.

## Что можно улучшить

- Перейти на разреженные матрицы и решатель с предобусловливанием.
- Читать имя сетки, `dt`, `Nt` и тип задачи из командной строки или файла входных данных.
- Проверить условия первого и третьего рода на задачах с известным решением.
- Добавить тесты: сравнение с точным решением как автоматическая проверка.
- Добавить элементы второго порядка и схему Кранка–Николсон (сохраняет монотонность не безусловно, но имеет второй порядок по времени).
- Построить измельчённые сетки для оценки порядка сходимости в норме C.
