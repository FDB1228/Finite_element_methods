# Метод конечных элементов: учебные и дипломный проекты

Три расчётных проекта на C++ (линейные треугольные элементы, библиотека Eigen), выполненные в МГТУ им. Н. Э. Баумана (факультет фундаментальных наук, кафедра прикладной математики). Каждый проект лежит в своей папке со своим README, исходным кодом, отчётом и презентацией; результаты проверены на задачах с известным решением.

| Проект | Задача | Метод | Проверка | Результат |
| ------ | ------ | ----- | -------- | --------- |
| [`Heat_eq_fem`](Heat_eq_fem/) | нестационарное уравнение теплопроводности в прямоугольнике | МКЭ, неявная схема Эйлера, сосредоточенная матрица теплоёмкости | точное решение T = exp(−2π²t) cos πx cos πy | порядок сходимости по L₂ около 2 |
| [`Elasticity_fem`](Elasticity_fem/) | двумерная линейная задача упругости | МКЭ, плоская деформация, разреженное разложение LDLᵀ | четыре тестовые функции с точным решением | порядок 2 по L₂ и C на пяти сетках |
| [`Diploma_fem`](Diploma_fem/) | натяг и контактное давление двух соосных труб после охлаждения | теплопроводность, термоупругость, контакт на независимых сетках, множители Лагранжа | решение Ламе для составного цилиндра | давление отличается от аналитического менее чем на 0,01 % (отчёт), порядок 2 |

## Что внутри каждой папки

```
<проект>/
├── docs/            # отчёт и презентация (PDF)
├── reports/figures/ # графики для README
├── src/             # исходный код, CMakeLists.txt, проект Visual Studio
├── tools/           # генераторы сеток, скрипты воспроизведения и графиков
└── README.md
```

## Сборка

Для всех проектов нужны компилятор C++17 и [Eigen](https://eigen.tuxfamily.org) 3.3 или новее (только заголовочные файлы). В каждом проекте:

```bash
cd <проект>/src
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Подробные инструкции по запуску, входным данным и воспроизведению таблиц из отчётов приведены в README каждого проекта. Сетки в проектах по теплопроводности и упругости строятся скриптами `tools/gen_mesh.py`, в дипломном проекте — `tools/gen_pipes_mesh.py`; программа Gridder2D, которой пользовались авторы работ, в репозиторий не входит.
