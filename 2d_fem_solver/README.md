# Численный расчёт натяга двух цилиндрических труб в двумерной области

Выпускная квалификационная работа (МГТУ им. Н. Э. Баумана, факультет фундаментальных наук, кафедра прикладной математики, 2026 г.). Программа на C++ методом конечных элементов решает связанную задачу для двух соосных полых труб: нестационарную теплопроводность, термоупругость при свободном охлаждении и контактную термоупругую задачу. Контактное давление не задаётся, а находится из условия совместности нормальных перемещений на границе труб. Результаты сравниваются с аналитическим решением для составного цилиндра (задача Ламе).

**Коротко:**

- две трубы после нагрева до 400 К охлаждаются до 300 К; их коэффициенты теплового расширения различаются в 10 раз, поэтому возникает натяг Δ ≈ 25 мкм и контактное давление около 221,5 МПа;
- расчёт идёт на четверти сечения (условия симметрии), трубы покрываются **независимыми** треугольными сетками, контакт полный и без трения;
- контактное условие накладывается на рёбра контактной дуги множителями Лагранжа; смешанная система решается разреженным LU-разложением (`Eigen::SparseLU`);
- по отчёту среднее контактное давление отличается от аналитического менее чем на 0,01 % на трёх сетках, остаточный зазор около 10⁻⁹ м;
- результаты воспроизведены независимо на сетках, сгенерированных скриптом из репозитория: давление сходится ко второму порядку (см. «Воспроизведение»);
- одна внешняя зависимость: библиотека Eigen; сборка через CMake или Visual Studio;
- в репозитории: исходный код, генераторы сеток, скрипты для воспроизведения и графиков, отчёт и презентация: [`docs/report.pdf`](docs/report.pdf), [`docs/presentation.pdf`](docs/presentation.pdf).

## Постановка задачи

Расчётные области (четверть кольца, a = 1 мм, c = 4 мм, b = 5 мм):

- внутренняя труба Ω₁: a ≤ r ≤ c, 0 ≤ φ ≤ π/2;
- внешняя труба Ω₂: c ≤ r ≤ b, 0 ≤ φ ≤ π/2.

В нагретом состоянии (T₀ = 400 К) трубы совмещены без натяга: внешний радиус внутренней трубы равен внутреннему радиусу внешней. Материалы одинаковы, кроме коэффициентов теплового расширения (E = 200 ГПа, ν = 0,33, λ = 30 Вт/(м·К), ρ = 10⁴ кг/м³, cₚ = 300 Дж/(кг·К), α₁ = 7·10⁻⁶ К⁻¹, α₂ = 7·10⁻⁵ К⁻¹). Значения подобраны для модельной задачи, а не для конкретной стали; модель плоского напряжённого состояния.

Типы границ в сетках: 1 — луч φ = 0, 2 — луч φ = π/2, 3 — r = a, 4 — контактная дуга внутренней трубы, 5 — контактная дуга внешней трубы, 6 — r = b.

**1. Тепловая задача** в каждой трубе: ρcₚ ∂T/∂t = ∇·(λ∇T), T(x, 0) = T₀; на контактной дуге T = T_c, на остальных границах теплоизоляция. Решение продолжается до max|T − T_c| ≤ 10⁻⁶ К, то есть до практически равномерного поля.

**2. Свободное охлаждение.** Каждая труба решается отдельно без контактного давления, температурная деформация ε_T = α(T − T₀)(1, 1, 0)ᵀ, на лучах симметрии u_y = 0 (φ = 0) и u_x = 0 (φ = π/2). Из радиальных перемещений контактных дуг находится натяг

$$\Delta_h = u^0_{c1} - u^0_{c2}, \qquad u^0_{ci} = \frac{1}{|\Gamma_c|}\int_{\Gamma_{ci}} \mathbf{u}^0_i\cdot\mathbf{e}_r\, d\Gamma .$$

**3. Контактная задача.** Те же уравнения для обеих труб вместе с условием полного бесфрикционного контакта на Γ_c:

$$(\mathbf{u}_1 - \mathbf{u}_2)\cdot\mathbf{n} = 0, \qquad \sigma_1\mathbf{n} = -p_k\mathbf{n}, \quad \sigma_2\mathbf{n} = -p_k\mathbf{n},$$

где **n** — нормаль к контактной дуге, направленная от внутренней трубы к внешней, p_k — искомое контактное давление.

## Аналитическое решение (проверка)

При однородной температуре свободное радиальное перемещение равно u⁰ᵢ(r) = αᵢ·ΔT·r, поэтому

$$\Delta_{an} = c\,(\alpha_2-\alpha_1)(T_0-T_c).$$

Из задачи Ламе для двух толстостенных цилиндров следует связь натяга и давления (зависимость от ν сокращается):

$$p_k^{an} = \frac{E\,\Delta}{2c^3}\cdot\frac{(c^2-a^2)(b^2-c^2)}{b^2-a^2}.$$

При T_c = 300 К: Δ_an = 2,52·10⁻⁵ м, p_k^an = 221,4844 МПа. Напряжения в трубах: σ_rr = A + B/r², σ_φφ = A − B/r² с коэффициентами из граничных условий (формулы в разделе 2 отчёта).

## Метод

1. **Сетки.** Линейные треугольные элементы, независимые сетки труб, построенные в Gridder2D; границы разных типов размечены отдельно. Координаты в файлах заданы в миллиметрах и при чтении переводятся в метры.
2. **Теплопроводность.** Метод Бубнова–Галёркина, элементная матрица K = |T|·λ·GᵀG (G — градиенты функций формы), диагональная («сосредоточенная») матрица теплоёмкости, неявная схема Эйлера; условие первого рода — заменой строк, решение `SimplicialLDLT`.
3. **Термоупругость.** Элементная матрица жёсткости A_T = |T|·BᵀCB и температурная нагрузка F_T = |T|·BᵀCε_T (B — матрица деформаций 3×6, постоянная на элементе, C — матрица плоского напряжённого состояния). Условия симметрии накладываются точным исключением степеней свободы (по координатам узлов на лучах φ = 0 и φ = π/2).
4. **Контакт.** Для каждого ребра контактной дуги внутренней трубы (slave) берётся середина, ищется ближайшее ребро внешней трубы (master) и проекция на него с параметром t. Остаточный зазор

   $$g_e = g_e^0 + \mathbf{n}\cdot\Big((1-t)\mathbf{u}_{m1} + t\,\mathbf{u}_{m2} - \tfrac12(\mathbf{u}_{s1}+\mathbf{u}_{s2})\Big) = 0, \qquad g_e^0=\mathbf{n}\cdot(\mathbf{x}_m-\mathbf{x}_s).$$

   На каждое ребро вводится один множитель Лагранжа λₑ, давление p_e = −λₑ. Система

   $$\begin{pmatrix} A_1 & 0 & G_1^T\\ 0 & A_2 & G_2^T\\ G_1 & G_2 & 0\end{pmatrix}\begin{pmatrix}U_1\\U_2\\\Lambda\end{pmatrix}=\begin{pmatrix}F_{T,1}\\F_{T,2}\\-g^0\end{pmatrix}$$

   (строки ограничений записаны без умножения на длину ребра, в столбцах множителей длина ребра учитывается; контакт считается активным на всей дуге). Среднее давление p_num = Σ Lₑpₑ / Σ Lₑ.
5. **Постобработка.** Напряжения вычисляются по элементам, σ = C(Bq − ε_T), переносятся в узлы осреднением с весом площади элемента, затем переводятся в полярные компоненты и напряжение Мизеса. Записываются отчёты и файлы для Tecplot.

![Сходимость давления](reports/figures/convergence.png)

Что показывает проверка натяга. При равномерном перепаде температуры точное поле перемещений u = αΔT·(x, y) линейно и воспроизводится линейными элементами точно, поэтому разность Δh и Δan не связана с дискретизацией МКЭ. На сетках с узлами точно на окружности Δh совпадает с Δan с точностью 6·10⁻⁷ % (остаток от того, что T отличается от T_c на 10⁻⁷ К). Поэтому порядок 2 для Δh в таблице отчёта, по-видимому, отражает точность приближения окружности сеткой Gridder2D, а проверка натяга подтверждает тепловой и термоупругий расчёты и масштаб сетки (миллиметры в метры).

### Поля напряжений

Расчёт на структурированных сетках, h = 0,125 мм (`tools/plot_fields.py`). Максимум напряжения Мизеса около 1,1 ГПа достигается на контактной дуге внешней трубы; значения получены в линейно-упругой модели с модельными свойствами материала.

![Поля напряжений](reports/figures/stress_fields.png)

Сравнение с решением Ламе вдоль луча φ = 0 (h = 0,0625 мм, p_k = p(Δan)): σ_φφ в обеих трубах, включая скачок при r = c, согласуется с аналитикой; радиальное напряжение близко к аналитическому внутри труб. Напряжения постоянны на элементе и осредняются по узлам, поэтому у границ погрешность больше: отклонение узловых σ_rr от Ламе доходит до 15 % от p_k на контактной дуге и до 8 % от p_k на свободной поверхности r = a, σ_φφ отличается не более чем на 6 % от p_k (максимум на r = a). В глубине труб (дальше 0,3 мм от границ) отклонения не превышают 3 % от p_k (`tools/plot_stress_profile.py`). Скачок σ_φφ на r = c физически оправдан: контакт без трения не требует непрерывности окружного напряжения.

![Профили напряжений](reports/figures/stress_profiles.png)

### Локальное контактное давление

Среднее давление определяется устойчиво, а давление по отдельным рёбрам (множители Лагранжа) осциллирует. В расчёте отчёта на сетке h = 0,125 мм (файл [`results/contact_pressure_h0.125.txt`](results/contact_pressure_h0.125.txt), 54 ребра, длиновзвешенное среднее 221,5011 МПа совпадает с таблицей) давление по рёбрам лежит в диапазоне 148–279 МПа. На структурированных сетках с одинаковым числом рёбер диапазон 165–276 МПа. Если же узлы труб на контактной дуге не совпадают (`--outer-factor 1.2`: 60 рёбер у внешней трубы и 50 у внутренней), осцилляции резко усиливаются, в части рёбер давление формально становится растягивающим (до −35 МПа), а среднее давление хуже (219,26 МПа при h = 0,125 мм, расхождение 1 %). Алгоритм устойчив для среднего давления и натяга, но локальные значения давления по рёбрам не следует использовать без сглаживания.

| `src/elasticity_contact_solver.h/.cpp` | `CoupledThermoMechanicalContact2D`: термоупругость, условия симметрии, контактные рёбра, множители Лагранжа |

**Порядок расчёта** в `main`: чтение сеток → условия симметрии → тепловая задача для каждой трубы до установления → свободное охлаждение (u⁰_c1, u⁰_c2, Δh, Δan) → контактная задача → средние давление и зазор, давление по формуле Ламе для Δh и Δan → напряжения → запись результатов.

**Параметры расчёта** заданы в коде (`diplom.cpp`): T₀ = 400 К, T_c = 300 К (можно передать аргументом), шаг по времени `dt` = 0,1 с, критерий останова 10⁻⁶ К, радиусы a, c, b, материалы труб, типы контактных границ 4 и 5, масштаб деформированной формы для Tecplot (50). Число тепловых шагов в таблице 2 отчёта соответствует шагу 1 с; на натяг и давление шаг не влияет, так как расчёт идёт до установившегося поля.

**Формат сетки** (читает `gridder2d_io.cpp`, нумерация с 1):

- `project_*.txt` — 6 непустых строк: файл описания области (программой не используется), файл узлов, файл элементов, файл границы, шаг сетки и число циклов оптимизации (не используются). Имена файлов читаются относительно папки проекта;
- файл узлов: `NN NBN`, затем NN строк `x y` (мм);
- файл элементов: `NE`, затем NE строк `n1 n2 n3 e1 e2 e3 v` (узлы, соседние элементы, подобласть);
- файл границы: `NBR`, затем NBR строк `n1 n2 E Type` (ребро, элемент, тип), затем `NRR` и NRR строк `n1 n2 E1 E2 Type` (внутренние ограничения; в расчёте не используются).

Формат файлов с сеткой отличается от формата курсовой работы по упругости (`Elasticity_fem`): там проект содержит три имени файлов, здесь шесть строк, а координаты переводятся из миллиметров в метры.

**Выходные файлы** (пишутся в рабочую папку): `result_report.txt` (сводный отчёт), `summary_table.txt` (таблица параметров), `inner_results.txt` и `outer_results.txt` (узловые значения: T, перемещения, напряжения), `stress_profile_phi0.txt` (профили по лучу φ = 0), `contact_pressure.txt` (давление и зазор по рёбрам), `tecplot_temperature_animation.dat` и `tecplot_deformed_fields.dat` (для Tecplot).

## Как собрать и запустить

Нужен компилятор с поддержкой C++17 и библиотека [Eigen](https://eigen.tuxfamily.org) 3.3 или новее (проверено на 3.4). Автор собирал проект в Visual Studio с Eigen 5.0.0. Eigen состоит только из заголовочных файлов: `sudo apt install libeigen3-dev` (Linux), `brew install eigen` (macOS), `vcpkg install eigen3` (Windows).

**CMake (Linux, macOS, Windows):**

```bash
cd src
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

**Visual Studio:** откройте `src/diplom.slnx`. В свойствах проекта путь к Eigen задан переменной среды `EIGEN3_INCLUDE_DIR` (C/C++ → Общие → Дополнительные каталоги включаемых файлов); создайте её или подставьте свой путь. Конфигурация x64.

**Запуск.** Программа принимает каталог сетки и (необязательно) температуру T_c в кельвинах. Каталог — полный путь, имя вида `grid_0125` или просто `0125`. Без аргументов используется `grid_0125` в рабочей папке.

## Известные ограничения

- **Только полный контакт заранее известной формы.** Контактная граница задана типами рёбер 4 и 5, все рёбра активны, активный набор не перестраивается, отслеживания отрыва нет. Контакт без трения и без проскальзывания по нормали; рёбра ищутся по проекции середины ребра внутренней трубы на ближайшее ребро внешней (проекция только в начальной геометрии).
- **Осцилляции множителей Лагранжа.** Давление по рёбрам осциллирует, а при несовпадающих узлах контактных дуг осцилляции становятся значительными (см. выше). Среднее давление и натяг определяются устойчиво.
- **Геометрия задана в коде.** Радиусы a, c, b, T₀ и типы границ заданы в `diplom.cpp` и должны соответствовать сеткам; температура T_c и каталог сетки передаются в командной строке. Формулы Ламе работают только для концентрических окружностей.
- **Температура только как начальное состояние механики.** Нестационарная задача решается до выравнивания, а механические перемещения и напряжения считаются по конечному, практически равномерному полю; термомеханика переходного режима не рассматривается.
- **Линейная упругость и плоское напряжённое состояние.** Пластичность не учитывается; свойства материалов модельные (α₂ = 7·10⁻⁵ К⁻¹), рассчитанные напряжения (до 1,1 ГПа по Мизесу) нельзя сопоставлять с пределом текучести конкретной стали. Режим плоской деформации есть в коде (`Material::plane_stress = false`), но не проверялся.
- **Точность напряжений.** Линейные треугольники дают постоянные напряжения на элементе; узловые значения, осреднённые по соседним элементам, у границ отклоняются от решения Ламе (до 15 % от p_k при h = 0,0625 мм).
- **Проверка на одной задаче.** Тест — осесимметричная задача с аналитическим решением; несимметричные нагрузки, другие области и материалы с разными E и ν не проверялись.
- **Эффективность.** Матрица тепловой задачи собирается и раскладывается на каждом шаге, хотя шаг по времени постоянен; для сеток из десятков тысяч узлов это не критично.
- **Сетки Gridder2D** строились внешней программой, в репозиторий не входит; файлы описания областей Gridder2D (первая строка `project_*.txt`) программой не читаются.
- **Нет автоматических тестов.** Контрольные сравнения с формулой Ламе выполняются в самой программе (`result_report.txt`) и в `tools/run_study.py`.

## Что можно улучшить

- Устранить осцилляции давления: стабилизированная формулировка, сглаживание множителей, мортарный метод (интегрирование по пересечению рёбер), выбор ведущей поверхности.
- Ввести активный набор контактных рёбер и итерации для задач с частичным контактом и отрывом; добавить трение.
- Задавать геометрию, материалы, T₀, T_c, шаг по времени и номера границ входным файлом, определять радиусы по сетке.
- Вычислять напряжения более гладким восстановлением (проекция на узлы по патчам), сравнивать с Ламе количественно по норме.
- Рассмотреть связанную термомеханику переходного режима, пластичность и температурную зависимость свойств.
- Перейти на плоскую деформацию и осесимметричную постановку, сравнить с двумерным расчётом.
- Добавить тесты (CTest) и автоматическую сборку.
